# ENTRY overview

Static, read-only dashboard hosted by GitHub Pages.

No account data, credentials, wallet keys, or trading code is included. The HTTPS API requires a separate read-only access code, entered in the page and kept only in page memory. The default is manual refresh; a visible opt-in enables 60-second refresh while the page is visible.

The API supplies financial summaries and service health, not individual trades. The page cannot submit orders.
